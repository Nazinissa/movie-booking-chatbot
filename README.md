# Movie Booking Chatbot

## Project Description
This project is an AI-powered Movie Booking Chatbot created using Antigravity AI and Gemini 3.5 Flash. The chatbot assists users in searching for movies, checking theatres and show timings, booking tickets, selecting seats, making payments, and managing bookings.

## Features
- Movie Search
- Theatre Search
- Show Timings
- Ticket Booking
- Seat Selection
- Ticket Pricing
- Payment Support
- Booking Confirmation
- Booking Cancellation
- Refund Management
- Offers and Discounts
- Booking History
- Ticket Download
- Rescheduling

## Tools Used
- Antigravity AI
- Gemini 3.5 Flash

## How the Chatbot Works
1. User selects a movie.
2. User chooses a theatre and show timing.
3. User selects seats.
4. Ticket price is calculated.
5. Payment is processed.
6. Booking confirmation is generated.
7. User can later cancel, reschedule, or download tickets.
